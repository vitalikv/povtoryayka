# Правила разработки «Повторяйки»

- Следуй требованиям `docs/POVTORYAYKA_PLAN.md`.
- Стек: HTML, CSS, TypeScript и Vite. Только DOM API, без React, Vue, Angular, JSX, UI-фреймворков и платных API.
- Интерфейс полностью на русском. Используй мягкие детские формулировки, без наказаний и оценки ребёнка.
- Разделяй DOM-компоненты, управление состоянием, распознавание, озвучку и хранение прогресса.
- Не сохраняй аудио. До первого запуска микрофона показывай уведомление взрослому о возможной передаче аудио браузерному сервису.
- Не представляй распознавание слов как логопедическую диагностику или оценку отдельных звуков. Не используй `confidence` для оценки слова.
- Награды — одна звезда за слово в круге. Общие звёзды и количество поздравлений не сбрасываются при новом круге.
- Инвалидируй попытку перед её отменой. Поздние события не должны влиять на новую карточку или попытку.
- Проверяй данные хранилища, при повреждении начинай с чистого состояния; при недоступности продолжай в памяти.
- После изменений запускай `npm test` и `npm run build`. Для интерфейса по возможности запускай `npm run test:browser` (установленный Google Chrome).
- Честно сообщай, что не проверено вручную, особенно реальный микрофон, русский голос и точность на детском голосе.
