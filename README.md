# Повторяйка

Бесплатный браузерный игровой тренажёр для ребёнка: послушать русское слово, повторить в микрофон и получить доброжелательную обратную связь. 20 карточек, четыре категории и копилка звёзд. Занимайтесь под наблюдением взрослого.

## Запуск

Нужен Node.js 22.12+ или 24+ и npm. В папке проекта:

```sh
npm install
npm run dev
```

Откройте адрес, напечатанный Vite (обычно `http://127.0.0.1:5173`). Для разработки используйте `localhost` или `127.0.0.1`; при публикации нужен HTTPS. Открытие `index.html` напрямую или через обычный HTTP-домен OpenServer не заменяет запуск Vite и не является целевым режимом работы микрофона.

```sh
npm test              # автоматические тесты без микрофона и сети
npm run build         # проверка TypeScript, включая тесты, и сборка в dist/
npm run preview       # локальный просмотр сборки
npm run test:browser  # браузерные проверки в установленном Google Chrome
```

Браузерные тесты сами запускают Vite на порту 4173. Порт должен быть свободен. Они подменяют распознавание, проверяют интерфейс, клавиатуру, адаптивность, уведомление взрослому и сохранение; снимки экрана сохраняются в `test-results/`. Если Chrome не установлен, сначала установите его. Тесты не запрашивают реальный микрофон. npm-кэш расположен в `.npm-cache/`, чтобы установка работала без доступа к пользовательской папке кэша.

## Как играть

1. Нажмите «Послушать». При наличии русского голоса слово прозвучит по-русски.
2. Нажмите «Повторить». Перед первым включением микрофона в текущем сеансе взрослый должен прочитать уведомление; затем браузер запросит разрешение.
3. Повторите одно слово. Точное совпадение нормализованного текста даёт одну звезду за это слово в текущем круге. Регистр, пунктуация, пробелы и различие `ё`/`е` не мешают совпадению. Похожие слова и фразы не засчитываются, уверенность распознавания не используется.
4. После каждых пяти новых звёзд появляется поздравление. Повторная попытка и перезагрузка не дублируют награды и уже показанные поздравления.
5. Переключайте карточки кнопкой «Следующее слово». После двадцатой можно явно начать новый круг: отметки слов очищаются, общая копилка и счётчик поздравлений сохраняются. Можно переходить дальше и без успешного распознавания.

Во время распознавания озвучка и повторный запуск заблокированы. При смене карточки попытка отменяется; её запоздалые события игнорируются. При уходе со страницы или переключении вкладки активные операции останавливаются.

## Браузеры, микрофон и приватность

Основная среда — Google Chrome на компьютере. Поддержка распознавания зависит от браузера, устройства, разрешений, сети и доступности сервиса. Если распознавания нет, остаётся режим «слушать и повторять» без автоматической оценки. Если нет русского голоса или синтеза речи, взрослый может прочитать слово вслух.

**Браузер может отправлять аудио внешнему сервису распознавания.** Работа без интернета и точность на детском голосе не гарантируются. Само приложение не записывает и не сохраняет аудио, не содержит сервера, регистрации, аналитики, рекламы или платных API. Обработка аудио браузерным сервисом регулируется условиями поставщика браузера.

Это **игровой тренажёр, а не медицинский или логопедический диагностический инструмент**. Распознанное слово не доказывает правильность произношения отдельных звуков. Несовпадение не означает речевую ошибку ребёнка.

Ограничения API: [SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition), [голоса синтеза речи](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices).

## Прогресс

Один объект `povtoryayka.progress` в `localStorage`: `version`, `currentWordId`, `awardedWordIds`, `totalStars`, `congratulationsShown`. Данные сохраняются только в этом браузере на текущем адресе сайта. Повреждённые или неподдерживаемые данные сбрасываются без ошибки. Если хранилище недоступно, игра продолжает работать в памяти и предупреждает о потере прогресса после перезагрузки. Для полного сброса удалите этот ключ в инструментах разработчика браузера.

## Структура

- `src/app.ts` — состояние, награды и переходы; без DOM и прямого обращения к речевым API.
- `src/components/`, `src/view.ts` — компоненты DOM и события интерфейса.
- `src/services/` — независимые обёртки над распознаванием и озвучкой.
- `src/utils/` — нормализация и проверка хранилища.
- `src/data/words.ts` — словарь; эмодзи используются как временные иллюстрации.
- `tests/` — проверки логики, повреждённых данных, тайм-аутов, озвучки и запоздалых событий.
- `e2e/` — проверки интерфейса в Chrome с подменой распознавания.

## Что проверить вручную на целевом устройстве

- Разрешение и отказ микрофона, отсутствие или занятость устройства, сетевые ошибки сервиса.
- Реальное русское озвучивание и появление голосов после их загрузки системой.
- Детский голос в тихой комнате; отсутствие обещаний точности или оценки звуков.
- Смену карточки во время настоящего распознавания и прекращение захвата микрофона.
- Планшет, экранную клавиатуру, скринридер и системное уменьшение движения.

Автотесты с подменой API не подтверждают качество распознавания и воспроизведение реального звука.
